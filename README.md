CrossCityFood
一个面向大学生的跨城市餐饮拼单平台。
CrossCityFood 希望解决一个简单的问题：
当用户想吃某个餐饮品牌，但所在城市或学校附近没有门店时，可以通过平台与其他用户共同下单，达到采购门槛后，由组织者统一采购并配送到指定取餐点。
项目以微信小程序为主要用户入口，使用 C++ 构建后端服务。
项目状态： 规划与开发初期

1. 项目目标
构建一个完整的餐饮拼单系统，实现从用户选餐、提交订单、订单聚合、达到采购门槛，到统一采购和配送的基本业务闭环。
首个版本采用小范围验证：
一个餐饮品牌
一个采购门店
一个大学取餐点
一个持续开放的拼单池
多个用户参与拼单
先验证业务是否真正可行，再逐步扩展品牌、门店和配送目的地。
2. 核心功能
用户端
拼单大厅：查看正在开放的拼单
拼单详情：查看采购门店、起送金额、截单时间
商品浏览：查看菜单、规格和价格
加入拼单：选择商品并提交订单
订单管理：查看个人订单和订单状态
配送信息：查看配送进度和取餐信息
拼单系统
创建和管理拼单池
设置最低采购金额
设置截单时间
自动统计订单金额和商品数量
管理拼单状态
处理订单取消和异常情况

管理端
创建拼单
管理品牌、门店和商品
查看全部订单
汇总商品采购数量
确认采购
更新配送状态
管理费用和异常订单
